# 🌌 csHangarin

> **Organize your work. Track your progress. Get things done.**

**csHangarin** is a modern and interactive task management web application built with **Django**. It provides users with a centralized workspace where they can organize tasks, categorize priorities, manage subtasks and notes, and visually track their productivity.

With its **Nebula-inspired interface**, smooth animations, customizable themes, progress indicators, and charts, csHangarin turns everyday task management into a clean and engaging experience.

---

## ✨ Features

### 🔐 User Authentication

csHangarin provides a complete user authentication system.

- 👤 User login
- 📝 Create an account
- 🔑 Password reset
- 🚪 Secure logout
- 🌐 Optional social login
  - Google
  - Facebook
  - GitHub

Users can start with traditional username/password authentication and enable OAuth providers when their credentials are configured.

---

### 📋 Task Management

Create and manage your work from one centralized dashboard.

- ➕ Create tasks
- ✏️ Edit tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 📅 Organize tasks by dates
- 🎯 Assign priorities
- 🏷️ Assign categories
- 📊 Track task completion

---

### 🧩 Subtasks

Break large tasks into smaller, manageable steps.

- Create subtasks
- Edit subtasks
- Delete subtasks
- Mark subtasks as completed
- Track progress toward completing a task

This makes complicated projects easier to manage one step at a time.

---

### 🏷️ Categories

Keep your tasks organized using custom categories.

Examples:

- 📚 School
- 💼 Work
- 🏠 Personal
- 💻 Programming
- 🎯 Projects

Create, edit, and remove categories whenever you need.

---

### 🚦 Priority Management

Set priorities to help identify what needs your attention first.

Priorities can be used to distinguish between:

> 🔴 High Priority  
> 🟡 Medium Priority  
> 🟢 Low Priority

This helps users focus on the tasks that matter most.

---

### 📝 Notes

Keep additional information alongside your tasks.

Notes can be used for:

- Ideas
- Reminders
- Important information
- Project details
- Quick thoughts

Create, edit, and delete notes directly from the application.

---

### 📈 Progress Tracking

csHangarin makes your productivity visible.

A **progress bar** gives users an immediate overview of how much of their work has been completed.
